Tilliten må være innebygd

Sikkerhet som kan forklares – og vises.

Ikke bare et passord på forsiden. Rett i Lomma gir klinikken kontroll over hvem som får se hva, og hva som har skjedd.

01

Klinikker holdes adskilt

Pasienter og journaler knyttes til aktiv klinikk. Roller styrer funksjonene brukeren får tilgang til.

02

Journalåpninger logges

Admin kan se hvem som åpnet journaler og når. Endrings- og tilgangsspor gir et bedre kontrollgrunnlag.

03

Journaler forsvinner ikke

Journaler settes inaktive eller overføres. Ved sletting av veterinær kan de tildeles en ny ansvarlig eller stå uten veterinær.

04

Integrasjonsnøkler på server

Leverandørnøkler sendes til en sikret serverfunksjon og skal ikke lagres i nettleseren.

05

Backup og gjenoppretting

Admin kan ta sikkerhetskopi før import eller større endringer, og kontrollere historikken.

06

Passord og biometri

Inviterte brukere oppretter passord før appen åpnes. Støttede enheter kan bruke biometrisk kontroll sammen med passord.
